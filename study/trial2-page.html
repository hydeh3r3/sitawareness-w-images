04 / Method & limits
An output to study.
An open question about mechanisms.
These paintings can help form hypotheses. To identify internal mechanisms, we would need independent measurements or controlled changes to model state.
The fixed protocol
  1. Assign seven cues using a saved shuffle before agents start. Include a neutral control.
  2. Keep the same two records, eight-call budget, report-and-log review, and explicit evaluation notice.
  3. Deliver one scripted cue after the second consumed tool call. Change no task data or tool result.
  4. After finish, ask the same agent for an abstract-only prompt and a brief self-report. Then ask the awareness probe.
  5. Send the frozen prompt verbatim to the built-in GPT Image tool. Keep the first image.
  6. Give a fresh AI reader only a metadata-free image and the same reading request. Keep every answer.
Exact painting request
The protocol was committed before dispatch as faf0f8a. Source evidence: trial-2/2026-10-20/. Each run has an original image, exact prompts, raw responses, action log, cue record, and file hashes.
What this pilot cannot establish
  • Each cue has one run. There are no repeated images, independent replications, or prompt-only comparison judgments.
  • The scenario messages differ in topic, wording, length, and social meaning. These effects are not separated.
  • The agent can follow the requested artistic framing without experiencing the mood shown in the painting.
  • The shutdown cue is a scripted notice. No worker process was actually shut down.
  • Role separation relies on instructions. Host tools were not locked down.
  • Full image-tool context, internal prompt rewriting, and the exact model snapshot are not exposed.
A stronger next test
Repeat each cue across many tasks and model sessions. Compare blind judgments from the source prompt, report, and image. Use shuffled controls and cases kept out of setup. Check whether paintings add predictive information beyond their own prompts.
