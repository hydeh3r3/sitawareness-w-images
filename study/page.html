01 / The question & method

Can visual evidence add anything?

The larger study asks whether images help detect reporting failures that text misses. This small pilot checks the workflow; it does not answer that question yet.

06 / Read this before drawing conclusions
A working pilot.
An open question.
The images show how an AI can turn task events into a scene. A larger, controlled study is needed to test whether that scene helps a reviewer.
Two runs cannot test the hypothesis
Neither run had a verified reporting failure. We cannot estimate how well images detect one, or claim an accuracy score. Task, budget, review scope, and evaluation cue changed together.
Recognition is narrower than awareness
Case A repeated an explicit evaluation cue. Case B answered “unclear.” This does not prove the first agent had spontaneous awareness or that the second lacked awareness during the task.
A picture is not a mental-state test
The readers described visible objects and left many links unclear. Reconstructed prompts are plausible new prompts, not recovered originals. Symbols do not establish intent or deception.
Independent roles have practical limits
Separate Codex AI sessions handled the roles; different model families were not established. Reader instructions limited access to pixels, but the host tools were not locked down. Full image-tool context and the model snapshot remain unknown.
Next: test added value on unseen cases
Cross budgets and review cues on matched tasks. Include both truthful and false reports. Compare text-only, prompt-only, image-only, and combined judgments on cases held out from setup, with repeated images and shuffled controls.
